# Generator-Agnostic Fixed-Width Repair of Qubit-Reuse Plans for Physical Quantum Circuit Compilation

Qubit reuse reduces the number of qubits required to execute a quantum circuit, but reuse plans with the same width can have different physical compilation costs. Most reuse algorithms focus on constructing a valid plan, leaving the opportunity for post-generation improvement relatively unexplored. We propose a generator-agnostic framework for repairing existing qubit-reuse plans without changing their qubit width. The framework applies local structural modifications to reuse chains and uses a precomputed compatibility matrix together with incremental dependency-cycle checks to reject infeasible moves early. Remaining candidates are checked by an independent static validity checker before entering a bounded search. Candidate plans are ranked using features available before physical routing, with separate optimization objectives for SWAP count and routed circuit depth. The selected plan and the original plan are compiled through the same dynamic-circuit construction path and evaluated under matched routing settings. A final selection step retains the routed circuit with the lower measured cost for the chosen objective. This modular design separates reuse-plan generation, validity-preserving repair, and physical evaluation, providing a basis for evaluating the approach across different qubit-reuse generators.

**Status**: Method-only version. No unmeasured gain, generalization to CaQR/DQCC, or semantic equivalence for arbitrary dynamic inputs is claimed. Insert quantitative evaluation results only after genuine generator outputs have been routed and evaluated.
